# 12주차 실습 - A-Frame 태양계 및 3D 모델 뷰어

A-Frame(WebVR/3D)을 활용한 태양계 시뮬레이션 및 10주차 실습 3D 모델 융합 프로젝트입니다.

## 🚀 주요 구성
- **박현준_202401500_DP_02반_12주차실습.html**: 태양계 행성들과 함께 10주차 3D 모델이 공전/자전하며 유영하는 씬
- **박현준_202401500_DP_02반_10주차실습.glb**: 10주차 실습에서 제작된 3D 오브젝트 모델
- **server.js**: 로컬 정적 웹 서버 (Node.js)

## 💻 실행 방법
1. 로컬 웹 서버 실행:
   ```bash
   node server.js
   ```
2. 웹 브라우저 접속:
   - [http://127.0.0.1:8080/](http://127.0.0.1:8080/)
